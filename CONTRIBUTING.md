# Contribuir

Usa Python 3.12 y un entorno virtual. Instala `requirements-dev.txt`, crea una rama descriptiva y ejecuta `python -m pytest -q` antes de proponer cambios. Añade pruebas cuando cambie la lógica de negocio, la validación o la API. Incluye pasos de reproducción en los reportes de errores.

El código se organiza en lógica de dominio, API, interfaz y pruebas. Evita dependencias de servicios externos para que la demostración siga siendo reproducible localmente.
